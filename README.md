# Automação de Cadastro de Itens

Projeto em Python que automatiza o cadastro de itens em [nome do sistema/site],
desenvolvido a partir do aprendizado no Python Intensivão da Hashtag Treinamentos.

## O que o projeto faz
- Lê os dados dos itens de [arquivo CSV/Excel]
- Abre/acessa [sistema ou site de cadastro]
- Preenche os campos de cada item automaticamente
- Repete o processo para todas as linhas da tabela

## Tecnologias usadas
- Python 3
- [pyautogui / pandas]

## Como executar
1. Clone o repositório:
   git clone https://github.com/seu-usuario/automacao-cadastro-itens.git
2. Instale as dependências:
   pip install -r requirements.txt
3. Execute:
   python main.py
